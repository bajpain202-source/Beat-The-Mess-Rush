## Featured Project

### [Beat The Mess Rush](https://github.com/verma2008-source/Beat-The-Mess-Rush)

A Design Thinking project focused on helping students understand mess crowd conditions and seat availability across breakfast, lunch and dinner.

**My role — Team Strategist**

- Planned the project workflow and execution approach.
- Helped shape the implementation strategy and organize the work into clear stages.
- Developed the website prototype using HTML, CSS and JavaScript.
- Built the main sections: Dashboard, Student Update and Manager Panel.
- Connected the website structure and features to the needs identified by the team.
- Co-developed the final project report with Samriti Verma; both team members contributed to all report sections.

## Website Features

- **Dashboard:** Shows meal-wise crowd information and seat availability.
- **Student Update:** Lets a student submit a crowd-level estimate.
- **Manager Panel:** Lets the manager update occupied seats and total capacity.

> The current prototype stores submitted updates in the browser using local storage. It demonstrates the interface and same-browser update flow; it is not yet a shared cloud database across devices.
